# nebrija-esc2-loto
En un buque militar se ha roto el gancho de la grúa que ayuda a transportar la munición de un lado a otro y necesitamos sustituirlo. Trabaja con cargas de 3 toneladas con una variación de alrededor de 500kg. Disponemos de acero inoxidable, fibra de carbono y aluminio para la construcción del gancho.
